# 泡泡月饼大作战 · 浏览器试玩版

[打开网页游玩](https://ryujou.github.io/bluearchive-mooncake-local/)

这是《蔚蓝档案》限时网页活动「月饼复制危机！泡泡月饼大作战」的非官方浏览器试玩版本。进入页面后可以手动游玩；点击左上角的「自动游玩」按钮可以切换自动操作。建议使用横屏浏览器。

本页面不需要游戏账号，不连接官方活动进度，也**不会发放或领取官方奖励**。分数只用于当前页面游玩。

## 素材来源与权属

角色形象、游戏画面、音乐、音效、字体及原活动游戏资源来自[《蔚蓝档案》官方网页活动](https://bluearchive-cn.com/webview/midautumn2026/)。活动信息可参见[《蔚蓝档案》官方公告](https://www.taptap.cn/moment/850040997285989326)。相关素材及游戏知识产权归各自权利人所有。本仓库是个人制作的非官方试玩页面，与官方无隶属或合作关系；注明来源不代表获得官方授权。

`autoplay.js` 是本地自动游玩脚本。页面通过 GitHub Pages 静态托管，直接访问上方链接即可游玩。
